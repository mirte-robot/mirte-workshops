.. card:: Package Delivery
    :link: https://github.com/MartijnWisse/mirte_workshop

    In this workshop, you will learn how to program the MIRTE Master robot
    to deliver packages. You will how to create a map using SLAM, how to
    move the arm, and add markers in the map. This workshop can be done
    indivually, or as a team assignment.
